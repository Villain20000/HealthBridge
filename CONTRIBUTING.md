# Contributing to HealthBridge OS

Thank you for your interest in contributing to HealthBridge OS!

## Code of Conduct

All contributors are expected to adhere to open-source community standards and maintain respectful communication.

## Development Workflow

1. Fork and clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Build all workspace packages:
   ```bash
   npm run build
   ```
4. Run automated tests:
   ```bash
   npm test
   ```
5. Ensure code is well-tested and documented before submitting a Pull Request.
