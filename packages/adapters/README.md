# @healthbridge/adapters

Healthcare format adapters for CSV, JSON and FHIR R4 JSON / NDJSON in HealthBridge OS.

**Status:** CSV and JSON adapters are supported in the v3.2.0 developer preview. The FHIR R4 JSON adapter is partial: structural inspection only, with no profile or terminology validation.

## Install

Install from source until the first npm release: `npm ci && npm run build`.

Published as `@healthbridge/adapters` when released.
