# @healthbridge/auth

API key authentication, scopes, workspace RBAC and per-key rate limiting for the HealthBridge OS platform API.

**Status:** Delivered with the Phase C platform work, which is unreleased at v3.2.0. The platform API is a developer preview.

## Install

Install from source until the first npm release: `npm ci && npm run build`.

Published as `@healthbridge/auth` when released.
