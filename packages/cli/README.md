# @healthbridge/cli

Standalone command-line tool for healthcare data inspection, transformation, validation and trace debugging.

**Status:** Supported in the v3.2.0 developer preview: `doctor`, `init`, `formats`, `inspect`, `transform`, `validate`, `trace`, `demo`, `plugins` and `examples` are implemented.

## Install

Install from source until the first npm release: `npm ci && npm run build`, then run `node packages/cli/dist/bin.js --help`.

Published as `@healthbridge/cli` when released.
