# @healthbridge/core

Core architecture, Canonical Medical Data Envelope and adapter interfaces for HealthBridge OS. Includes the adapter registry with capability manifests and detection scoring.

**Status:** Delivered in v3.1.0 as part of the developer preview.

## Install

Install from source until the first npm release: `npm ci && npm run build`.

Published as `@healthbridge/core` when released.
