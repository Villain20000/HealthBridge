# @healthbridge/fhir-r4

FHIR R4 resource typings and builders for HealthBridge OS.

**Status:** Resource definitions and builders ship with the v3.2.0 developer preview. Profile, terminology and referential validation are not implemented here.

## Install

Install from source until the first npm release: `npm ci && npm run build`.

Published as `@healthbridge/fhir-r4` when released.
