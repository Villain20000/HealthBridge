# @healthbridge/persistence

Tenant-scoped persistence for HealthBridge OS: MySQL migrations, workspace-scoped repositories, cursor pagination and idempotency.

**Status:** Supported with MySQL 8.0+ (migrations run at boot) and in-memory repositories in the unreleased Phase C developer preview. MySQL 5.7 and MariaDB are refused at boot with a reason.

## Install

Install from source until the first npm release: `npm ci && npm run build`.

Published as `@healthbridge/persistence` when released.
