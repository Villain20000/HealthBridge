# @healthbridge/sdk

Standalone TypeScript SDK for HealthBridge OS with inspect, detect, transform, replay and trace export over files or inline input.

**Status:** Supported in the v3.2.0 developer preview. It wraps the same engine as the CLI, and a parity test keeps their output byte-identical.

## Install

Install from source until the first npm release: `npm ci && npm run build`.

Published as `@healthbridge/sdk` when released.
