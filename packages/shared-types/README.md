# @healthbridge/shared-types

Shared TypeScript types and interfaces for HealthBridge OS, including the Canonical Medical Data Envelope, tracing and validation contracts used across the monorepo.

**Status:** Supporting package delivered with the v3.1.0 developer preview. Its shape can still change before a stable release.

## Install

Install from source until the first npm release: `npm ci && npm run build`.

Published as `@healthbridge/shared-types` when released.
