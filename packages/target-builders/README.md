# @healthbridge/target-builders

Target-format resource builders for HealthBridge OS that enforce required FHIR elements before export and inject `meta.profile`.

**Status:** Delivered in v3.2.0 for Patient, Observation, Specimen and DiagnosticReport.

## Install

Install from source until the first npm release: `npm ci && npm run build`.

Published as `@healthbridge/target-builders` when released.
