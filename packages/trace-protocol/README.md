# @healthbridge/trace-protocol

Normalized transformation trace protocol and tracing engine for HealthBridge OS. Trace protocol v1.1 is redacted by default and records staged transformation events.

**Status:** Delivered in v3.1.0 as part of the developer preview.

## Install

Install from source until the first npm release: `npm ci && npm run build`.

Published as `@healthbridge/trace-protocol` when released.
