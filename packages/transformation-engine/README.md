# @healthbridge/transformation-engine

End-to-end transformation orchestration for HealthBridge OS, combining adapters, mappings, validation, target builders and traces.

**Status:** Delivered in v3.2.0 and used by the supported CLI and SDK transformation paths.

## Install

Install from source until the first npm release: `npm ci && npm run build`.

Published as `@healthbridge/transformation-engine` when released.
